# 🐳 Docker Study Vault

A free, self-contained Docker learning hub: notes, an interactive architecture diagram, Q&A, a practice exam, hands-on labs and a command cheatsheet.

**Live site:** https://deven1003.github.io/study-vault-docker/

## What's inside

- **Core topics:** images, containers, volumes, networking, Dockerfiles, Compose and more
- **Interactive Docker architecture:** click through the client, daemon, registry and objects
- **Questions & answers** for interview and exam prep
- **Practice exam** to test yourself
- **Hands-on practice labs**
- **Practical use cases**
- **Command cheatsheet** for day-to-day use

## Run locally

Everything is in a single `index.html`, so there's no build step:

```sh
git clone https://github.com/deven1003/study-vault-docker.git
cd study-vault-docker
# open index.html in your browser
```
